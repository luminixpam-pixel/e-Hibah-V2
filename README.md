# e-Hibah-V2
Sistem Informasi E-Hibah Universitas YARSI merupakan aplikasi berbasis web untuk mengelola proses pengajuan, verifikasi, review, persetujuan, monitoring, dan pelaporan hibah penelitian secara terintegrasi. Sistem ini dirancang untuk meningkatkan efisiensi, transparansi, dan akuntabilitas pengelolaan hibah di lingkungan Universitas YARSI.
