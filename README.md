# E-Hibah Universitas YARSI

**Sistem Informasi Pengelolaan Hibah Penelitian Universitas YARSI**

## Tentang Proyek

E-Hibah Universitas YARSI merupakan aplikasi berbasis web yang dikembangkan untuk mendukung digitalisasi proses pengelolaan hibah penelitian di lingkungan Universitas YARSI.

Sistem ini dirancang untuk mengintegrasikan seluruh tahapan pengelolaan hibah, mulai dari penyampaian informasi dan pengajuan proposal, verifikasi administrasi, proses review dan seleksi, penetapan penerima hibah, hingga monitoring, evaluasi, dan pelaporan hasil penelitian.

Melalui sistem ini, proses pengelolaan hibah diharapkan menjadi lebih efektif, terstruktur, transparan, dan terdokumentasi dengan baik.

## Tujuan Pengembangan

- Mempermudah dosen dalam memperoleh informasi dan mengajukan proposal hibah.
- Mengintegrasikan proses verifikasi dan persetujuan proposal.
- Mendukung proses review dan seleksi proposal secara terstruktur.
- Mempermudah pengelolaan anggaran dan dokumen hibah.
- Memfasilitasi monitoring kemajuan pelaksanaan penelitian.
- Mendukung pengumpulan laporan akhir dan luaran penelitian.
- Meningkatkan transparansi dan akuntabilitas pengelolaan hibah.

## Fitur Utama

### 1. Pengajuan Proposal
- Melihat informasi dan persyaratan skema hibah.
- Mengunduh template proposal, RAB, dan panduan.
- Membuat proposal baru.
- Memilih skema hibah.
- Menambahkan data anggota tim.
- Mengisi Rencana Anggaran Biaya (RAB).
- Menyimpan proposal sebagai draft.
- Mengirim proposal dan memperoleh nomor pengajuan.

### 2. Verifikasi dan Persetujuan
- Verifikasi administrasi proposal.
- Pemeriksaan kelengkapan dokumen.
- Validasi plafon RAB.
- Validasi kuota skema hibah.
- Validasi tanggungan laporan.
- Pemberian catatan revisi dan tindak lanjut.

### 3. Review dan Seleksi
- Pengelolaan proses review proposal.
- Penilaian proposal oleh reviewer.
- Mendukung mekanisme blind review.
- Pengelolaan hasil seleksi dan rekomendasi.

### 4. Pelaksanaan dan Monitoring
- Pengisian logbook pelaksanaan penelitian.
- Pengunggahan laporan kemajuan.
- Monitoring perkembangan kegiatan penelitian.
- Penyusunan Rencana Tindak Lanjut (RTL) hasil monitoring.
- Pengunggahan bukti perbaikan hasil monitoring.

### 5. Pelaporan dan Luaran
- Pengunggahan laporan akhir.
- Pengumpulan luaran penelitian.
- Dokumentasi publikasi dan Hak Kekayaan Intelektual (HKI).
- Pengelolaan dokumen hasil pelaksanaan hibah.

### 6. Dashboard dan Notifikasi
- Dashboard berdasarkan hak akses pengguna.
- Informasi status pengajuan hibah.
- Monitoring tahapan proses hibah.
- Notifikasi informasi dan tenggat waktu.
- Ringkasan data pengelolaan hibah.

## Teknologi yang Digunakan

- **Backend:** Laravel
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** MySQL
- **Version Control:** Git dan GitHub

## Pengguna Sistem

Sistem dirancang untuk mendukung beberapa peran pengguna, antara lain:

- Dosen / Ketua Pengusul
- Anggota Tim Peneliti
- Verifikator Fakultas
- Pengelola LPPM
- Reviewer
- Pimpinan Universitas
- Bagian Keuangan
- Administrator Sistem

Setiap pengguna memiliki hak akses dan tanggung jawab sesuai dengan perannya dalam proses pengelolaan hibah.

## Alur Umum Sistem

1. Dosen melihat informasi dan skema hibah.
2. Dosen membuat dan mengisi proposal.
3. Dosen melengkapi data tim dan RAB.
4. Proposal dikirim untuk proses verifikasi.
5. Proposal melalui proses review dan seleksi.
6. Hasil seleksi dan penetapan penerima hibah diproses.
7. Penerima hibah melaksanakan kegiatan penelitian.
8. Dosen mengunggah laporan kemajuan dan laporan akhir.
9. Luaran penelitian dan tindak lanjut monitoring didokumentasikan dalam sistem.

## Status Pengembangan

Proyek ini dikembangkan sebagai sistem informasi pengelolaan hibah penelitian Universitas YARSI secara terintegrasi. Pengembangan dilakukan secara bertahap berdasarkan kebutuhan proses bisnis dan rancangan sistem.
